# About Daedalus

Daedalus Runtime provides a Lua API for building server-side Minecraft experiences aiming to completely replace the built-in DataPack system with much cleaner and faster Lua code.

This documentation will help you use the Runtime as well as act as a helpful reference for API specification.

## Getting started

Begin with the **Getting Started** guide on the sidebar to the left, then explore the API reference to see what else you can do using Daedalus.
