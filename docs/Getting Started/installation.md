# Installation

Daedalus supports the latest full release of Minecraft. When necessary, a long-term-support (LTS) version for the preceding Minecraft release is also maintained. The version requirements below may therefore change over time.

## Prerequisites

- Minecraft 26.2
- Fabric Mod Loader 0.19.3
- Fabric API 0.19.3

Daedalus is designed to be more performant than Minecraft's built-in datapack system; it has no additional performance requirements beyond those of Minecraft itself. However, in extreme cases if you are running many modules or one extremely demanding one the recommended ram amount is 8GiB.

## Installation

1. Set up a valid Fabric or QuiltMC instance on your dedicated server or development environment.
2. Place `Daedalus.jar` in the instance's `mods` directory.
3. Start Minecraft or the server once. Daedalus will generate its required files during this initial launch.

And you're done! Daedalus is now installed and ready to configure.
